# ایرانسل‌یار 3.3.0 — راهنمای نصب

## نصب در Chrome / Chromium
1. فایل ZIP را استخراج کنید.
2. به `chrome://extensions` بروید و **Developer mode** را روشن کنید.
3. روی **Load unpacked** کلیک کنید و پوشه‌ای را انتخاب کنید که `manifest.json` مستقیماً داخل آن است.
4. سایت رسمی `https://my.irancell.ir/` را باز کنید و وارد حساب شوید.
5. روی آیکون ایرانسل‌یار کلیک کنید؛ پنجره کوچک قبلی نمایش داده می‌شود.
6. برای بازکردن داشبورد ماندگار کنار صفحات، از پنجره کوچک دکمه `◨` / «بازکردن داشبورد در سایدبار» را بزنید.

## تحلیل مصرف جداگانه
- مانده بسته عادی و شبانه برای پیش‌بینی با هم جمع نمی‌شود.
- بسته شبانه‌ای که ساعتش در عنوان مشخص است، فقط در همان پنجره مصرف محاسبه می‌شود؛ مثلاً `02:00 تا 07:00`.
- پس از ارتقا، برای ساخت نرخ‌های جدید باید چند نمونه تازه در ساعات مجاز بسته‌ها ذخیره شود. مانده‌های قدیمی که مشخص نیست مختص هر بسته بوده‌اند یا مقدار کلی حساب، عمداً «نامشخص» می‌شوند؛ اطلاعات نام و اعتبار بسته‌ها حفظ می‌شود.

## قابلیت سایدبار
- پنجره کوچک همچنان برای بررسی سریع در دسترس است.
- سایدبار داشبورد کامل، بسته‌های فعال، پیشنهادهای قیمت، تحلیل مصرف، تاریخچه، CSV و تنظیمات هشدار را دارد.
- برای بازشدن از داخل پنجره کوچک، روی دکمه سایدبار کلیک کنید؛ بازشدن برنامه‌ای سایدبار باید در واکنش به کنش کاربر باشد.
- حداقل نسخه مورد نیاز Chrome: 116.

## نکات
- افزونه مستقل از ایرانسل است و رسمی نیست.
- برای کارکرد API، ورود معتبر به سایت ایرانسل لازم است. APIهای استفاده‌شده، API عمومی تضمین‌شده نیستند و ممکن است تغییر کنند.
- توکن به‌صورت پیش‌فرض در `chrome.storage.session` می‌ماند؛ نگهداری ماندگار در تنظیمات اختیاری است. تاریخچه و کش در فضای محلی مرورگر ذخیره می‌شوند. از نصب افزونه فقط در مرورگر و پروفایل مورد اعتماد استفاده کنید.
- برای به‌روزرسانی دستی، در `chrome://extensions` روی Reload بزنید.
- جزئیات پردازش اطلاعات در `PRIVACY-POLICY.md` است. نگهداری پایدار توکن اختیاری و به‌صورت پیش‌فرض خاموش است.
